# Vehicle-Sales-Analytics-PowerBI
Interactive Power BI dashboard analyzing vehicle sales performance, regional trends, revenue insights, and operational KPIs using DAX and data visualization.
Vehicle Sales Analytics Dashboard
Overview

This project is an interactive Power BI dashboard designed to analyze vehicle sales performance, regional sales trends, revenue metrics, and operational KPIs. The dashboard helps identify sales patterns, high-performing regions, and business growth opportunities through data-driven analytics.

Tools Used
Power BI
DAX
Excel
Data Modeling
Features
Sales trend analysis
Revenue KPI tracking
Regional performance comparison
Interactive filters and slicers
Category-wise sales analysis
Dynamic dashboard visuals
Key Insights
Identified top-performing sales regions
Analyzed revenue growth trends
Compared vehicle category performance
Evaluated sales distribution across regions
